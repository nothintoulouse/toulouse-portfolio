# Brayden Toulouse — Portfolio

Source for **[portfolio.toulouse.cloud](https://portfolio.toulouse.cloud)**. Next.js App Router, deployed on Vercel.

This repository is the portfolio *implementation* — a single-page site with case studies. It is not the technical work it describes. For that, see [agent-cli](https://github.com/nothintoulouse/agent-cli), [voice-inventory-core](https://github.com/nothintoulouse/voice-inventory-core), and [Lautrec](https://github.com/nothintoulouse/Lautrec).

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## About the case-study imagery

The BEO Dashboard and See Also screenshots in `public/` are **synthetic demo data**. Event names, clients, pricing, guest counts, and dietary figures were fabricated for the case study. No real client, guest, or employer data appears anywhere in this repository or on the deployed site.

The two production applications shown are deliberately not linked: one is internal employer software and the other is access-gated. Screenshots only, by design.
